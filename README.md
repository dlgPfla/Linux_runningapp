# Linux_runningapp

## 프론트엔드 구현 설명

### 프론트엔드 역할

- React와 TypeScript를 사용해 사용자가 코스를 확인하고 러닝을 기록할 수 있는 화면을 구성함.
- Vite를 사용해 프론트엔드 개발 및 빌드 환경을 구성함.
- Kakao Map API를 사용해 서대문구 공원 위치, 유동인구 혼잡도, 선택한 러닝 루트를 시각화함.

### 주요 화면

- 홈 화면에서 전체 코스 수와 조건별 추천 코스를 확인할 수 있도록 구현함.
- 코스 전체 화면에서 난이도, 혼잡도, 거리 등의 조건으로 코스를 필터링하도록 구현함.
- 지도 화면에서 공원 대표 마커를 선택하고 해당 공원의 코스 목록을 확인하도록 구현함.
- 내 기록 화면에서 러닝 횟수, 누적 거리, 누적 시간과 러닝 히스토리를 확인하도록 구현함.

### API 연동

- `/api/courses` 응답을 받아 실제 코스 데이터를 화면에 표시함.
- `/api/population` 응답을 받아 Kakao Map 위에 유동인구 혼잡도 마커를 표시함.
- `/api/course-routes` 응답을 받아 `course_id`를 기준으로 선택한 코스와 루트 좌표를 매칭함.
- 매칭된 좌표를 이용해 지도 위에 루트 점과 선, 출발 및 도착 위치를 표시함.

### 러닝 기록 흐름

- 코스에서 러닝을 시작하면 선택한 코스 정보를 `currentRun` state에 저장함.
- `RunningTimer`에서 시작 시각을 기준으로 경과 시간을 1초마다 계산함.
- 러닝 종료 시 코스 정보와 경과 시간을 `records` state에 추가함.
- 러닝 기록은 DB나 브라우저 저장소가 아닌 프론트엔드 state로만 관리하며, 새로고침 시 초기화되는 구조임.
